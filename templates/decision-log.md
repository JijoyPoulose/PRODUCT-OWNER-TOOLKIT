# Decision Log

Record product decisions **when they're made**, so no one has to reconstruct them six months later. One entry per decision, newest on top.

---

## DEC-000: [Decision title]

| Field | Value |
|---|---|
| Date | YYYY-MM-DD |
| Status | Proposed · Accepted · Superseded by DEC-___ |
| Decider | [Name, role] |
| Consulted | [Names / teams] |
| Related | [Epic, PRD, story links] |

**Context:** What situation forced a decision? What constraints apply?

**Options considered:**

| Option | Pros | Cons | Est. cost / effort |
|---|---|---|---|
| A. | | | |
| B. | | | |
| C. Do nothing | | | |

**Decision:** We chose **[option]**.

**Rationale:** Why this option beats the others *given the constraints above*.

**Consequences:** What becomes easier, what becomes harder, and what we'll watch for.

**Revisit trigger:** The condition that would make us reconsider (e.g. "volume > 10k/day", "regulation X changes").
